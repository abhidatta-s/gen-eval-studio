# eval/

`sample_run_mock/` is output from the **mock** generator only. Mock output is fake and
deterministic (built from canned phrases and each prompt's variables), so these numbers
say nothing about how any real model performs.

It was generated by:

```
python3 run.py --out eval/sample_run_mock
```

Real-model numbers are not included because none were run.

Files: `results.json`, `results.csv`, `report.html` (open it in a browser).
